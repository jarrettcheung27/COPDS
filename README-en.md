# COPDS: DNA Storage Simulation Platform

COPDS is a Streamlit-based demo platform for DNA data storage simulation. It provides an end-to-end pipeline to encode images into DNA strands, simulate DNA storage/sequencing channel effects, and decode to reconstruct the original image. This project is designed for research demos and reproducible experiments.

![alt text](Snapshots/Homepage.png)

## Highlights

- End-to-end image-to-DNA and DNA-to-image workflow
- Outer 16-ary LDPC + inner BCH pipeline
- DNA channel simulation (synthesis, decay, PCR, sequencing)
- Reproducible intermediate files for analysis
- Streamlit UI for quick experiments and demonstrations

## Quick Start (Windows)

### 1) Requirements

- Windows 64-bit
- Python 3.12.x 64-bit from python.org (enable "Add Python to PATH")
- Microsoft C++ Build Tools (MSVC v143) for compiling the pybind11 extension

### 2) Create and activate a venv

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3) Install dependencies

```powershell
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

### 4) Build the FFTQSPA extension

```powershell
Set-Location Encode\Nonbinary
python setup.py build_ext --inplace
```

Verify the output file exists:

- `Encode/Nonbinary/fftqspa.cp312-win_amd64.pyd`

### 5) Run the app

```powershell
Set-Location ../..
streamlit run Webapp.py
```

Open the URL shown in the terminal (usually http://localhost:8501).

## Usage Guide

### Encode and Store in DNA

1. Select **Encode & Store in DNA** mode in the sidebar and click "submit".
2. Adjust the DNA channel parameters to simulate different storage conditions.
![alt text](Snapshots/Channelparams.jpg)
4. Select encoding parameters (currently fixed to the default values).
![alt text](Snapshots/Codeparams.png)
3. Upload one or more image files (`jpg`, `jpeg`, `png`). Click **Submit** to start encoding and store data to DNA Library.
![alt text](Snapshots/Fileupload.JPG) 
6. The app generates DNA pools and simulated DNA data.
![alt text](Snapshots/Runsimulation.JPG)


**Outputs**:
- Input DNA pool: `DNA_Library/{file_id}_in.dna`
- Simulated DNA pool: `DNA_Library/{file_id}_out.dna`
- Intermediate files: `Mid_data/`
- Metadata: `config/config.json`

### Restore from DNA

1. Select **Restore from DNA** mode in the sidebar and click "submit".
![alt text](Snapshots/Restoremmode.JPG)
2. Choose stored file(s) from the list.
![alt text](Snapshots/Selectfile.JPG)
3. Click **Submit** to start decoding.
4. The restored image is written to `Restored_files/`.
![alt text](Snapshots/Restoredfilepreview.JPG)

## Project Structure

- `Webapp.py`: Streamlit entry point and orchestration
- `Helper_Functions.py`: segmentation, DNA/binary transforms, BCH/LDPC wrappers
- `Encode/Nonbinary/`: FFTQSPA codec sources and compiled extension
- `Model/Model.py`: DNA channel simulation
- `config/config.json`: persistent metadata
- `DNA_Library/`: DNA pools
- `Mid_data/`: intermediate files
- `Restored_files/`: reconstructed outputs
- `Analysis/e2e_run_default_jpg.py`: end-to-end validation


## Notes

- The app is a research demo, not a production service.
- Some historical DNA pools generated by a legacy pipeline are incompatible with the current correct decode path; re-encode if needed.
- If `fftqspa` import fails, rebuild the extension under `Encode/Nonbinary/` using the active venv.
